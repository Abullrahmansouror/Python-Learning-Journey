- round(x): A function that rounds a decimal number to the nearest whole integer.
Example:
    x = 3.14
    result = round(x)  # Rounds 3.14 to the nearest integer
    print(result)     # Output: 3

- abs(x): A function that returns the absolute value of a number (it converts negative numbers into positive numbers, while keeping positive numbers unchanged).
Example:
    x = -5
    result = abs(x)    # Removes the negative sign (distance from 0)
    print(result)     # Output: 5

- pow: A function that raises a number (base) to the power of another (exp).
Ecample:
    result = pow(2, 3)  # Calculates 2 * 2 * 2
    print(result)       # Output: 8

- max: Displayed the big number between x, y, z
Example:
    x = 12
    a = 19
    y = 18
    results = max(x, a, y)
    print(results)

- min: Displayed the smallest number between x, y, z
Example:
    x = 12
    a = 19
    y = 18
    results = min(x, a, y)
    print(results)
