## **DAY 17 OF PYTHON LEARNING JOURNEY**
### What I have learned:
- random.randint(): This generate a random output from x to y.
Example:
    import random 
    print(random.randint(x, y))

- random.choice(): This generate a random choices in my variables.
    import random 
    chioces = ("x", "y")
    print(random.choice(chioces))
