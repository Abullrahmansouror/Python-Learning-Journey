## **DAY 1 OF PYTHON LEARNING JOURNEY**

### What I have learned:
- Typecast: changing one data type into another.
Example:
int()	Integer	            int("10") → 10
float()	Decimal number	    float("10") → 10.0
str()	String/text	        str(10) → "10"
bool()	True/False	        bool(1) → True


- input: lets the user type something into your Python program.
Example:
    input("Type your name")
