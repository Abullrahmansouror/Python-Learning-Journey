## **DAY 1 OF PYTHON LEARNING JOURNEY**

### What I have learned:

- print(): It's a Python function used to display something on the screen.
- Variables: A container for a value (string, float, integer, boolean).
  It's like a box 📦 where I can store everything and call it later.
  - String: Text or characters written inside quotes.
  - Integer: A whole number, without decimals.
  - Float: A number that has a decimal.
  - Boolean: A value that can only be True or False.

Example:
### variable string
first_name = "Abdulrhman"
print(first_name)

### Also I can write it like this
first_name = "Abdulrhman"
print(f"Hello {first_name}")


### variable integer
birth = 2007
print(f"Your birth is {birth} Thanks!")


### variable float
price = 10.99
print(f"Item price {price} after discount")


### variable boolean
is_student = True
if is_student == True:
    print("You are a student")
else:
    print("You are NOT a student")
