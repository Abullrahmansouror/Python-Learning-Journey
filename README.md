# Python Learning Journey

Welcome to my **Python Learning Journey**!

This repository documents my progress as I learn Python from the ground up. My goal is not only to learn the language but also to build a consistent habit of learning, practicing, and documenting what I learn every day.

## About This Repository

This repository serves as my personal learning journal. Each learning day has its own folder containing:

- Notes explaining the concepts I learned.
- Practice code and experiments.
- Small exercises to reinforce my understanding.
- Quizzes to test what I learned.
- A summary of the day's learning.
- Questions or topics to revisit later.

I previously started this journey and reached Day 10, but I took a break and eventually stopped learning. Instead of continuing from where I left off, I decided to start again from **Day 1** and build a stronger foundation.

This time, I want to focus not only on learning Python but also on developing the discipline and consistency to keep going.

Rather than keeping my notes private, I've decided to make this repository public so anyone can follow my progress, learn alongside me, clone my journey, or even suggest improvements.

## Goals

- Learn Python step by step from the fundamentals.
- Build a consistent learning habit.
- Practice by writing code every day.
- Understand concepts instead of simply memorizing them.
- Create small projects to apply what I learn.
- Track my progress over time.
- Become a better problem solver through practice.
- Share my journey with the community so others can follow my progress, learn alongside me, and benefit from my experience.

## Feedback

If you notice a mistake, have a suggestion, or want to share a better approach, feel free to open an issue or submit a pull request. I'm always happy to learn from others.
